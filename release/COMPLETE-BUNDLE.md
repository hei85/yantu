## 本次补齐方式

姿态模型、两个线稿模型和 Whisper 文件直接读取维护者本地已有文件，
按原字节复制并校验，不用下载脚本占位。25 个模型及配套文件在公开
清单逐项登记。姿态、线稿共用的 Hugging Face 缓存快照和版本指针也
随包复制；Whisper 使用本地目录，不依赖维护者的个人缓存路径。

完整包同时同步当前 Git 登记的全部源码与文档，避免运行二进制已更新
而 ZIP 内源码或隐藏规则仍旧的情况。未变的运行依赖沿用既有完整包，
每个文件保持原 SHA-256。模型与工具按各自原许可使用。

## 检查范围

发行装配逐文件校验实际 ZIP 内容、文件大小、SHA-256、模型缓存路径、
技能数量与原技能文件。完整包校验结果另附 JSON，下载文件另附 SHA-256。
这些是文件完整性记录，不是新增模型推理、浏览器逐按钮或成片质量
验收；未执行付费生成，也未修改维护者在用软件。

个人 API Key、数据库、项目、生成素材和日志不是共享软件组件，不在
公开包中。接收者首次启动建立自己的本机数据并填写自己的 Axon Key。
