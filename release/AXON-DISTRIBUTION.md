版本：`v1.6.0-axon.4`，2026-10-08。目标仓库仍为 `hei85/yantu`，
保留既有 Git 历史。此策略仅存在于公开发行源码，维护者的在用版本
未被替换或施加同样限制。

## 模型中心与执行边界

模型设置恢复原有的“添加模型 / 已接入 / 创作默认”布局和入口。
服务地址的 Axon 限制由后端校验；添加单个模型仍核对真实目录，
不会因此开放任意供应商。修复系统代理地址被前端误过滤导致各用途
均显示 0 个模型的问题。文本目录导入默认使用纯文本输入合同；旧版
缺少文本能力声明的记录也按纯文本恢复，不推断视觉能力。

本版补齐随包技能的实际注册：47 个制作技能首次启动自动加入接收者的“我的技能”，保留正文及参考文件，重复启动按稳定 ID 和内容哈希同步版本，保留显式移除与收藏。维护者软件中已安装的五个技能包共 421 个原文件保留，包含 Remotion 4.0.534 的 141 个文件、整片制作 1.6.1 的 15 个文件及 H3 官方四个原文件。完整在用规则原文保存在 `PORTABLE_AGENT_RULES.md`。详细范围见 [技能库与规则迁移](SKILL-LIBRARY-FIX.md)。

- 模型 API 基地址固定为 `https://zh.heihan.dpdns.org/v1`，使用者填写
  自己的 Axon API Key。仓库没有内置渠道密钥。
- 前端只显示已登记的系统 Axon 渠道。后台创建、更新渠道也校验固定
  地址，关闭自定义渠道和前台模型开关不能由保存配置重新开放。
- 模型须从 Axon 实际 `/models` 目录拉取并导入。不能手工创建任意
  模型 ID，不能将已导入模型的调用 ID 改成目录外名称。
- 真实模型调用要求登记的系统渠道；执行层和模型重定向仍检查 Axon
  HTTPS 主机。声明式协议不能用绝对外站地址逃过限制。
- 自定义模型代理返回拒绝。直连 RunningHub / AutoDL 的模型工作流
  不属于本发行版可执行入口；相关适配源码保留，供阅读其原实现。
- MCP Runtime 未挂载 Dreamina 直连 CLI 路由。画布、制作编排、
  本机空间与图像分析、媒体处理、剪辑和时间线入口保留。
- 媒体结果和参考资源可能位于 CDN，继续使用既有 SSRF 策略；不将
  普通媒体下载误判为模型调用。

分辨率、画幅和时长按真实目录能力、已登记协议或明确标识的推断
显示。实际输出仍需媒体探测与审看；菜单显示 2K 不能证明结果一定
具有相应细节。未实测的上游能力不能标成已验证。

## 源码与启动

包含 `web/`、`backend/`、`canvas-agent/`、`plugins/yingce/`、
`plugin-packages/`、集成、脚本和规则。排除依赖目录、可执行运行时、
私人配置、数据库、操作记录、生成媒体及额外下载的分析模型权重。

Windows 源码启动见根 README。启动器只使用本仓库的 `.local/`
SQLite 数据目录，先检查本机端口，启动失败只停止自己创建的进程。
不执行安装插件脚本就不会切换当前 Codex 的插件来源。

MiniMax H3 官方四个原文件随包提供，由安装脚本离线逐文件校验
SHA-256；仅缺失或损坏时联网恢复。中文适配及制作自检规则随仓库提供。官方文本保留官方
来源，不被本仓库的新增内容许可重新授权。

发布页的 `Yantu-v1.6.0-axon.4-Windows-x64.zip` 是预构建便携包，
包含运行环境、依赖、MCP、插件、技能、合成工具以及允许再分发的
深度和抠图权重。完整解压后双击启动，不需安装开发工具。
用户数据首次启动创建，不从维护者使用中的软件复制。
OpenPose / lineart 权重按原作者许可另行初始化，见快速开始。
容器镜像仍未在本次构建或发布，不能据此认为 GHCR 镜像可拉取。
