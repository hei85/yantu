# v1.6.0-axon.3 模型设置修复

- 恢复原有的添加模型、已接入、创作默认页面及对应入口，不使用另做的模型中心页面。
- 保留原有表单、模型编辑、批量拉取、导入导出操作；服务地址固定为 Axon，后端继续核对真实模型目录。
- 修复系统模型目录使用 `/api/<channelId>`，发行过滤却只接受另一种代理地址，导致已配置模型全部从创作列表消失的问题。
- 文本模型首次导入补齐纯文本能力配置；已有缺失配置按同样的纯文本默认恢复，不自动开放图像或视频理解能力。
- 这次变更只发布到 GitHub 发行版；维护者本地软件不覆盖。

## 已安装用户

关闭衍图，解压 `Yantu-v1.6.0-axon.3-Model-Center-Fix.zip`，把里面的文件
覆盖到原软件目录，再运行 `启动衍图.cmd`。保留原目录中的 `.local` 和
`canvas-agent-config`，补丁不含这些目录。已有服务端模型与 Key 不需要删除重建。
已打开的网页需要刷新一次以载入新前端。

首次使用者下载完整的 `Yantu-v1.6.0-axon.3-Windows-x64.zip`。

## 检查范围

本次前后端编译通过。启动独立浏览器校验服务被自动安全检查拒绝
（仅返回 `blocked by policy`），不能据此声称已完成浏览器逐按钮
或新用户真实 Key 的导入验证。模型配置不会自动提交付费生成请求。
