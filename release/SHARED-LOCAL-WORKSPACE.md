# Codex 与浏览器共用本机数据

版本：v1.6.0-axon.6。

## 修复内容

原先画布索引和个人素材列表保存在各浏览器的 IndexedDB，Codex 内置浏览器与 Edge/Chrome 无法读取彼此的列表。新版以同一个软件实例的后端数据库为保存来源，浏览器保留缓存和迁移前备份。

1. 启动时先确认本机用户身份，再从后端读取画布、资产、分类、回收站、插件元数据和绘图。
2. 首次进入旧浏览器时，将已有记录和浏览器专属媒体迁入本机服务，保留原始记录。已经上传的资源保持原 ID，不重新生成图片或视频。
3. 后续保存携带版本号，服务端通过事务检查；旧窗口或空浏览器不能用过期的整份快照覆盖较新的数据。
4. 素材库和画布列表在空闲时检查其他窗口更新。正在编辑的画布显示“同步最新内容”，避免覆盖未完成操作。
5. 网络失败保留当前数据和待保存修改，显示重试入口；连接失败不会切成空白匿名工作区。
6. 绘图原稿和渲染图都通过后端保存；共享媒体纳入资源引用检查，避免被误判为孤立文件。

## 使用边界

- Codex、Edge 和 Chrome 必须连接同一份已启动的软件服务和同一用户；不同安装目录、不同机器或不同账号不会自动合并。
- `localhost:3000` 和 `127.0.0.1:3000` 连接同一服务时读取同一套后端数据。窗口偏好可以独立保存。
- 便携版仍自动建立本机使用身份，模型中心页面和操作保持原样，仍只允许 Axon 模型。
- 初次迁移先在原先有数据的浏览器中打开并等待保存完成，再打开其他浏览器。若旧媒体无法读取，原记录保留并提示原因，不假装迁移完成。

## 从旧版更新

1. 关闭旧软件并备份其 `.local/app-data` 和 `canvas-agent-config`。浏览器中的原记录也不要清除。
2. 下载发布页的完整软件，或较小的 **Workspace-Update.zip**。更新包只包含更新的应用文件与源码，不含个人数据库、密钥或项目。
3. 将更新包内文件解压到原软件根目录并覆盖同名文件。不要删除 `.local`、`canvas-agent-config` 或用户自己的项目/媒体目录。
4. 双击原目录的 `启动衍图.cmd`；数据库自动增加 schema 37 的工作区文档与历史表，原数据表和媒体不删除。
5. 在原先有资产的浏览器中打开原本的网址，等待首次迁移；然后用另一浏览器连接同一个服务。

完整包的顶层目录名称随版本改变。若选择完整包覆盖更新，应将该顶层目录**里面的文件**复制到原软件根目录。只在新目录独立启动会使用该新目录的数据，不能代替旧目录更新。

## 保存接口

- `GET /api/workspace/documents?key=...` 读取当前用户文档。
- `GET /api/workspace/documents` 读取当前用户的文档版本。
- `PUT /api/workspace/documents` 提交 `key`、`value`、`baseRevision`，冲突返回 409。
- 只接受列出的工作区类型及绘图键，不接受任意凭据/账号配置。首次迁移版本和最近十个版本保留用于恢复。
