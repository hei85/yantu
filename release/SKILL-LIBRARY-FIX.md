# 随包技能库与规则迁移

## 修复原因

旧包虽然带有插件技能目录，但后端只初始化广场技能，没有把这些文件注册为接收者已加入的技能。因此软件“我的技能”和画布可调用技能列表没有实际显示随包技能。

便携模式启动现在使用本安装目录的 `plugins/yingce/skills/`，注册 47 个技能及其完整文件包，为当前本地用户创建加入关系。用户可在原来的“我的技能”中查看正文、参考和脚本，画布与 MCP 使用相同的技能 API。无需复制维护者数据库或安装 Codex 才能在软件内查看。

## 迁移清单

| 内容 | 对照与处理 |
| --- | --- |
| 衍图整片制作 1.6.1 | 对照维护者实际安装包，15 个文件逐字节一致，包含固定空间三步、机位、距离、跨镜衔接、自检、声音和交付 |
| FFmpeg 技能 | 实际安装包的 35 个文件逐字节一致 |
| Higgsfield 技能树 | 实际安装包的 226 个文件完整保留，包含子技能与两个空输出目录说明模板 |
| Remotion 4.0.534 | 以软件实际安装包为准，同步 141 个文件及上游来源；原插件目录是较旧版本 |
| MiniMax H3 官方指南 | 固定提交 d21241f0a4b3acbb34c97dae47fa417b7065e438，官方正文、两份模式指南和代理描述下载后分别核对 SHA-256，再注册；仓库保留原有加载适配和中文连续性规则 |
| MCP、插件与调用规则 | 保留原插件、制作参考、跨客户端启动器及技能读取 API；本次不改模型服务策略 |

相同技能目录使用稳定 ID，内容未变不创建新版本。升级保存新包版本，用户主动移除、收藏和独立固定版本的状态保留；用户自行创建的技能不被覆盖。技能脚本仅作为文件提供，本次自动安装不执行技能中的脚本。

H3 官方内容按原发布者条款获取，没有重新授权。下载失败会明确提示；普通画布和其他技能仍可使用，不能声称 H3 指南已准备完成。私人项目、媒体、数据库、密钥、日志和旧备份不随公开软件分发。

## 验证边界

文件一致性、构建和发行完整性分别记录，不能代替接收者电脑的逐功能操作验证。核心制作规则属于执行约定；仍需要支持 MCP 的 AI 客户端读取规则并调用真实工具，不能保证模型每次生成都符合规则，也不能在没有实际审看和听审时声称质量通过。
