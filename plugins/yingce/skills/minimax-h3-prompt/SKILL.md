# MiniMax H3 提示词适配

适配当前衍图渠道，不把历史单片模板当作通用规则。用户的当前剧本、真人/动画选择、语言、时长、声音和引用要求优先。

## 官方指南与实际能力

1. 先核对渠道模型完整 ID、操作、参考图数量、时长、画幅/分辨率、首尾帧及音频能力。普通多图参考不是强制关键帧或尾帧控制；官方其他接口的上限不能替代当前渠道声明和实测。
2. 读取相邻 `h3-prompt-writing/SKILL.md`。文本/首帧/首尾帧/尾帧模式读 `references/base-en.txt`；全参考模式读 `references/ref-en.txt`。它来自 [MiniMax 官方仓库](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing)，本适配层不是官方技能。
3. 全参考模式依次采用 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`；保持真实标签及保留关系一致。按用户要求中文描述正文，必要字段名与 `<Picture N>`、`<Subject N>`、`<d>` 保留，不用英文段落替代中文。

## 四阶段与承接

- 先完成人物、场景、道具独立图并验收；真人需要同一身份正/侧/背三视图，保留正脸锚点。有道具就准备有效参考并实际使用。
- 根据内容决定单镜头长度和四个关键状态。直接连接所需资产生成该镜四宫格，按左上、右上、左下、右下切图。全片本轮所需图片检查通过并锁定版本，再按镜头关联。
- 前镜采用第4切图只提供连续状态，下一镜第1格必须是动作已推进的新关键时刻，不能复制前镜画面。当前本片Picture 1—4为自己的四张独立切图，Picture 5为身份，Picture 6为前段结束状态（首段用场景）；实际首帧是本段切图1。第4切图为结束参考，严格尾帧以真实渠道能力为准。核验最多6张的当前上限并按资源去重，不用母图。详读相邻`yingce-film-production/references/video-continuity.md`。
- 各图的真实智能 `@` 放在正文对应状态/动作旁，与实际输入顺序一致；不集中堆在顶部。每两个阶段之间写清重心、肢体、视线、道具、灯光及摄影机怎样连续变化，不能仅写“自然过渡”。
- 四图是四个时间阶段的视觉参考，不是四幅并排输出或四段幻灯片。提示词时间属于创作目标，实际效果必须检查。
- 将身份、固定空间与道具的保留，和动作/表情/机位的发展分开写入retention_analysis。不要笼统要求整幅参考“完全保持”，也不要把每张阶段图定义成不同人物。每镜写本轮新动作、物理路径与结尾出口；依赖镜按剧情顺序验收采用。

## 对白、风格与声音

- 对白/旁白优先在镜头中段完整说完，开头留承接，末尾留词尾、呼吸、表情和出口。15 秒可先安排约 3–11 秒对白，再按读本时长调整；长台词延长或按句意拆镜，不截断、不擅自改文、不强行加速。详细方法读相邻 `yingce-film-production/references/voices-dialogue.md`。
- 在对应动作段写准确起止时间、说话人、原文与语气；台词用 `<d>[普通话] 原文</d>`。主角不说话时注明实际声源，不让旁白/门外声音错误变成主角嘴型。
- 视觉风格按本片锁定，真人写真实摄影、肤质与衣料，动画按本片既定画风。场景灯光、天气变化由剧情明确规划，不一概禁止变化。
- 音乐按场景、情绪和节奏规划，相关镜头保持统一并自然缓入缓出；不默认全片无音乐，也不默认每镜都有。原生音轨与重配音频按本次运行模式执行。
- 默认不加字幕或片尾文字，用户以后明确要求时按新指令。

## 提交与采用

分镜行的采用资源、智能引用、可见线和真正送出的图片必须一致。视频只继承对应分镜行的输入；超时重查原任务，改提示词或参考视为新输入，不能假用旧成功结果。生成后检查四阶段顺序、身份/空间/道具、真实时长/像素、对白完整性与衔接。音轨存在和 ASR 命中不能冒充听感或口型验收。

完整制作与自主恢复读相邻 `yingce-film-production/SKILL.md` 及其 `references/canvas-production-rules.md`、`references/agent-automation.md`。
