# Agent 接续与技能适配

适用于衍图便携版的整片自动化。当前任务先服从用户最近的目标：整理规则时完成文档和安装；制作时按正式流程交付。用户未来要求创建单独自动化时，再用实际自动化工具设置触发条件，不把“明天我会让你创建”当作已创建的定时任务。

## 本次归纳的自动化与空间规则

从剧本接管制作、迁移历史纠正与区分通用/单片要求，读 [自动化工作流](script-to-film-automation.md)。房型图和建模准备仅用于封闭室内；户外不强制。跨镜距离读 [空间距离与连续性](spatial-distance-continuity.md)，不把相机远近造成的投影变化写成人物或桌子移动。

## 一次完整制作的执行合同

1. 通过本插件真实 MCP 确认便携版进程、当前 canvasId、业务 projectId 与可用工具。固定目标，读取最新画布、素材、分镜和已有 runId。
2. 从剧本提取故事节拍、角色、场景、道具、准确台词及用户目标长度。按内容决定镜头长度，设定交付帧数、真人/动画风格、声音与字幕选择；沿用已明确授权。
3. 先完成人物、场景和道具独立参考。真人有同一身份的正/侧/背全身三视图，并保留正脸锚点；有道具就准备并实际引用。基础资产不是四个剧情阶段。
4. 为每镜规划四个关键状态、完整动作范围、过渡和对白中段窗口。前镜第4图只提供连续状态，不能复制成后镜第1格；后镜首格已有新动作推进。直接引用所需合格图生成，全部母图与切图逐张验收后锁定版本。
5. 逐镜关联自己的四张独立切图，首帧为本段切图1；本片再加身份及前段结束参考（首段为场景），最多6张唯一图片。前镜末格仅是连续状态参考。同步真实节点/资源ID、可见线、内联原生@和实际编号，核验渠道上限。视频只从对应分镜行继承，不重复拉照片到视频；读video-continuity.md。
6. 先验收代表性风险镜头，合格结果复用。独立任务按现有并发限制执行；共享画布写入和依赖前镜真实出口的操作顺序执行。每步保留真实模型、能力版本、技能版本、输入、taskId、attemptId 和采用资源。
7. 逐镜分别检查技术媒体、画面内容、参考顺序、人物/空间/道具连续性和实际声音。台词完整说完，采用裁切不吃首尾字；没有听审或口型证据就注明该项未验证。保留成功素材，只修受影响部分，不能拿原成功任务冒充改词后的结果。
8. 编辑真实时间线，匹配目标帧数。配乐按剧情统一规划且自然进出，相关镜头用环境声/音乐桥；不逐镜随意重启。默认无字幕及结尾文字，保留原生声音；用户以后新要求优先。
9. 合成后先完成整片内容检查和后期产物登记，再执行交付核验，避免在前置检查未写回时误报失败。将新成片放回清楚标注的可见节点，回读播放入口和采用资源；整理受影响区域，只有用户要求整体整理时才重排整个画布与视口。

每批画布维持“图像 → 分镜 → 视频”的阅读顺序，文档另区，媒体分别可见、网格均衡、留白一致。历史媒体保留但清楚标识，不能覆盖用户已采用的新版本。

## 断线与中断恢复

- 检查当前运行状态和原 taskId，按 nextPollAt/retryAfterMs 查询；查询错误或超时不等于生成失败。
- 当前插件绑定正确时，先等待/诊断自动重连。需要浏览器重载时，使用当前提供的浏览器控制能力对已核实的目标标签页操作；回读 URL、canvasId 和诊断确认恢复。工具不能控制时才向用户说明必要动作。
- 重载后从持久 ProductionRun、任务、资产版本及画布继续，不能重新收费生成、切换旧目录、盲目把旧任务结果挂回采用图。
- 检查证据应包括 status、评估者和具体观察；后期 artifactId 使用 `timeline:master`，versionId 使用该步骤真实输出 resourceId，inputFingerprint 从当前步骤读取。
- 对使用的软件技能保存真实 skillId/versionId/contentHash/phase。文件系统里读过一个技能不等于软件清单已有对应版本；准备和登记技能须在生成前完成，制作中途不偷偷切版本。

## 外部技能的采用方法

先读来源正文和所需参考，再按当前软件的真实工具适配。以功能匹配、原始作者来源、维护状态和可复现结果选技能；GitHub 星数不是使用人数，也不能证明效果最好。新技能不自动增加生成接口、口型工具或 GPU 能力。

截至 2026-10-03，本次实际查阅并采用的来源：

| 来源 | 吸收的可用方法 | 在衍图中的落点 |
| --- | --- | --- |
| [MiniMax 官方 h3-prompt-writing](https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing) | 按真实输入模式选择指南；参考编号和保留关系一致；准确台词与声音结构 | 只用于 H3 视频提示词，保留官方结构/标签，按用户要求中文正文、阶段内联 `@`、中段对白；渠道限制独立核验 |
| [Higgsfield Canvas 技能](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-canvas/SKILL.md) | 素材作为节点、按阶段排列依赖、图像融合、前镜出口延伸 | 直接图片引用生成阶段图，再按分镜行生成视频，保留可見线与可复用采用版本 |
| [Higgsfield Pipeline 技能](https://github.com/OSideMedia/higgsfield-ai-prompt-skill/blob/main/skills/higgsfield-pipeline/SKILL.md) | 剧本/分镜/图像/视频分阶段处理；身份与动作分开；保留成功部分、定位失败 | 对应持久 ProductionRun 和分项检查，修改一镜不回滚其他合格素材 |
| [ComfyUI-Agent-Kit 作者说明](https://github.com/SlavaSexton/ComfyUI-Agent-Kit) | 先查节点真实输入类型再执行；保存工作流；模型知识按需读取；队列与画布可见结果分别处理 | 使用衍图 schema、stateHash、能力版本、任务记录和原生时间线；完成任务后回挂真实媒体并核对显示 |

这些来源的软件专有工具、接口、账号流程与局部模型参数不能直接套进衍图。Higgsfield 的“无内置时间线”、ComfyUI 的本地 GPU 配置等不适用于本便携版，按衍图当前接口执行。官方英文输出偏好也不覆盖用户的中文要求。

## 小范围改进循环

每次出现实际失败时，记录镜头、输入版本、症状、实测证据和修复结果。先区分提示词、参考、能力、任务恢复、显示和剪辑问题，再修直接原因。只有可迁移的发现进入规则；单片的动画风格、天气、配乐选择、长度不能升级成所有影片的硬要求。既有成功规则保留，过期冲突规则移出入口，历史记录可追溯。
