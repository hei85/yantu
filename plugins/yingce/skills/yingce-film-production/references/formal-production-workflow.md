# 正式制作流程：从剧本到漫剧或真人风格短片

本流程采用动画和真人影视的前期、制作、后期方法；以下十一阶段、数据字段和 MCP 检查是衍图执行方案。行业没有适用于所有影片的唯一工序表，项目规模可不同，但故事、设计、镜头、素材和成片之间必须可追溯。“验收”由 Agent 检查真实产物，不要求用户逐步点确认。

## 执行与恢复

先读 [画布制作规则](canvas-production-rules.md)。本片所有所需图片完成并检查合格后，逐镜选择实际需要的资产，再由对应分镜行生成视频；每镜资产集合独立确定。

先读当前画布、业务项目、模型能力和 ProductionRun。沿用用户已给的剧本、片长、画幅、模型系列、声音要求及费用授权。没有正式剧本时可整理流程或做明确标记的功能试验，不能把自编测试片宣称为用户的整片。

每阶段保存：阶段 ID、所用剧本/资产版本、产物引用、检查结果、问题及受影响镜头。结果分为通过、需修改、未验证；接口调用成功不能代替内容验收。已通过且输入未变的阶段可复用。改动使依赖该输入的检查失效，保留先前任务和文件。沿用授权，不反复要求确认。

基本顺序：接收 → 拆解 → 视觉方案 → 粗分镜 → 资产 → 声音 → 锁镜/分镜粗剪 → 样片 → 逐镜制作 → 后期 → 交付。设计、粗分镜和读本可在前期并行；批量视频必须收齐依赖产物。单节点测试只检查指定功能，不能代替正式整片前期。

## 1. 接收剧本与要求（brief）

**输入：** 用户剧本和已有参考。

**工作：** 保存剧本原文/版本，明确漫剧、AI 真人风格或实际真人拍摄；记录目标总时长、画幅、交付帧率/分辨率、语言、字幕、声音及指定模型/系列。普通创作细节自主补全，只有会改变故事、目标时长或必要授权的缺项才问用户。

**产出与进入条件：** 有可读剧本、制作简报和可计算的交付长度。推断事项明记，测试故事不能冒充正式剧本。片头、片尾、转场都占总时长，例如 180 秒、25 fps 的成片终点为 4500 帧。

## 2. 剧本分析、场景拆解与连续性（script_breakdown）

**工作：** 按场景赋予稳定 scene_id，记录地点、内外景、故事日期/时段、出场角色、动作、原文台词、目的/情绪转折、必要道具/服装/特效和预计银幕时长。区分剧情必要信息与可自由发挥的细节。

建立连续性表：角色在相邻场的外观、情绪、位置、伤污和持有道具，场景时间/光线与动作起止。区分故事时间和剪辑顺序，列出矛盾。

**产出：** 场景表、角色表、场景/道具/服装需求、台词表、连续性表、时长分配。

**进入条件：** 所有故事节拍有归属，人物/台词不会被提示词随意改写，各场预计长度合计能解释片长。对白先读本估时，不套“一页必等于一分钟”的换算。

## 3. 视觉方案（visual_design）

**工作：** 确定统一画风、配色、材质、光线、摄影与构图。角色写固定识别特征、服装版本、体态/年龄感；地点写空间、入口/出口、主要物件/光线；道具写外观、尺度、持有者和剧情状态。

封闭室内的固定房间按 [固定空间三步流程](fixed-space-workflow.md) 先确定房型和尺度，再建立同一几何模型与机位表，从模型导出真实取景检查后，才制作场景外观和关键帧。保存房型资源、模型源/版本、机位参数与渲染资源；沿用已通过阶段。多个相连室内空间用同一坐标关系，门洞、家具和间距不因反打或拉远重建。户外开放场景不强制房型图或建模。人物与家具的距离使用同一测量锚点，实际走位才更新；详见 [空间距离与连续性](spatial-distance-continuity.md)。

**产出与进入条件：** 风格说明、角色/场景/道具设计表、所需视角。先用设计草案或已有图评估，明确哪些属性锁定、哪些随剧情变化。真人风格关注服化道与摄影；漫剧关注轮廓、线条、配色和角色辨认。

## 4. 粗分镜与镜头覆盖（rough_storyboard）

**工作：** 逐场拆镜，初排景别/视角、主体动作、机位/运镜、进出画、台词/反应及必要插入镜头。分配稳定 shot_id/row_id，记录叙事作用、粗略秒数，复核视线、动作方向、轴线和信息衔接。

**产出与进入条件：** 覆盖全故事的粗分镜，可用文字、草图或已有参考；为资产指出需要的角度、表情、姿态。关键动作/台词都有镜头，不能靠无关空镜填剧情。此时允许增删镜头，不标作最终锁镜版。

## 5. 人物、场景、道具参考资产（asset_package）

**工作：** 按需求逐项复用或生成，先复用已检查的项目/画布图片。单资产单次图片请求数量默认 1；角色、场景、道具分别登记，避免九宫格混入多个身份。确实需要更多角度/资产才增加独立参考。

检查脸、发型、服装、体态、场景空间、道具尺度和画风；核对真实图片方向/尺寸。按模型支持规格准备画面，小幅对齐误差按合同处理，不能把横竖颠倒当作误差。参考资源必须能按本渠道实际支持的方式传输。

**产出：** 真实 asset_id/version_id/resource_id 或节点、主参考、检查意见及镜头映射。首尾帧分别记 start_frame/end_frame，不能依赖参考列表顺序猜用途。

**进入条件：** 本片所有所需图片，包括计划中的镜头首尾帧/关键图，都有真实、已检查、可读取的版本，再逐镜实际关联采用资产。缺图先补图，不能只写“同一个人物”就算身份锁定；不需要某类资产的镜头明确记为不需要，只绑定本镜所需图片。

## 6. 声音方案、人物声线与读本（sound_plan）

**工作：** 逐句记说话人、原文、情绪、停顿、语言和时间。对白优先放在镜头中段，开头留承接、结尾留词尾与反应；先估时或读本实测，放不下就调整镜头，不能截断句子。决定原生音频、参考声音驱动或经用户要求的独立配音；默认保留 `NATIVE_AUDIO`，不擅自去原声重配。

要求固定人物声音时绑定实际 VoiceProfile/VoiceVersion 或合法参考声音。不同女主也有独立身份，不能只按男女共用声线。核实模型接参考音频、输出声音及对白/身份/口型能力。临时读本用于节奏；配音驱动镜头依据真实音频长度，不截词尾凑秒数。

**产出与进入条件：** 台词/说话人表、可执行声音路径、声线绑定及音频/读本引用。无对白项目记录环境声/音乐方案；无声音交付明确不需要。音轨存在、ASR 命中、人耳清晰、声音身份、口型分别检查，未听验记未验证。详见 [对白与声音绑定](voices-dialogue.md)。

## 7. 最终镜头表与分镜粗剪锁定（locked_storyboard）

**工作：** 对照实际资产、读本、模型限制修订粗分镜；把板格/已有图、时间码与临时声音排成分镜粗剪（Animatic），检查叙事、停顿和总长度。普通场景可用静帧，复杂动作补关键姿态，不必先为每个板格付费生视频。

每镜记录 scene_id/shot_id、叙事目的、起止状态、景别/机位/运动、动作/表演、准确台词/说话人、资产版本与用途、参考/首尾帧用途、模型操作/规格、最终采用帧数及区间。复杂镜头补时间节拍/站位/视线，简单空镜简写。

**产出：** 最终分镜版本、时间码/板格粗剪、镜头资产引用、采用时长表、模型策略/能力版本。

**进入条件：** 镜头与转场覆盖等于目标帧数，故事可读、资产齐备、对白放得进镜头。按模型合法长度拆片段，不传超范围参数。锁定后改剧本、参考版本、台词或长度必须升版本并复核依赖。

## 8. 代表性样片与能力验证（pilot）

**工作：** 挑能覆盖风险的少量镜头，如近景对白、多图身份、首尾帧、复杂运镜。用实际接入模型/版本试制，复用符合本项目需求的已有证据。样片可在设计时提前试，批量生产仍须锁定版；合格样片直接采用，不重复生成。

**产出与进入条件：** 真实任务/样片、参数、检查意见、失败原因和适用范围。关键功能通过或已有实测替代镜头方案。用户限定 MiniMax H3 时只选该系列，不偷偷换模型。试验沿用用户 2–3 秒等限制，不能把试验长度硬设成全部正式镜头时长。

## 9. 逐镜制作与返工（shot_production）

**工作：** 按计划依赖分批提交，引用锁定资产/模型规格；动作接续用前镜真实输出或指定首尾帧。保存提示、模型/能力版本、参数、参考用途、run/step/attempt/task_id 和幂等键。

回查原任务，登记真实结果到镜头、资产与画布。检查身份、动作、服化道、空间、头尾、实际长度、画幅、声音、台词/说话人及同步。只返工失败片段，保留通过素材；提交状态不明先查原任务，不重发计费。

**产出与进入条件：** 按 shot_id 管理的候选/采用镜头、真实资源、采用区间、返工和未验证项；故事/台词覆盖齐全，采用镜头通过内容/技术检查，缺镜列具体补制动作。

每批结束都通过 MCP 检查画布并整理受影响区域，规划、人物/场景/道具、视频、音频、成片分区，用均衡网格留白。保留不相关手工布局；只有用户要求整体重排时才整理整张画布，不能无限横排、重叠或重复创建。

## 10. 剪辑、声音、调色与字幕（postproduction）

**工作：** 组装剪辑 → 节奏修订 → 锁画，检查相邻镜头、对白停顿和故事信息。需要补镜时补有叙事作用的镜头，不循环素材掩盖缺镜。统一画幅/帧率，以保持比例裁切/留边，不拉伸人物。

锁画后做镜间色彩匹配，处理对白/环境声/音效/音乐层次和字幕同步；原声与重配台词不能重复播。片头、片尾、转场计入目标长度。

**产出与进入条件：** 可编辑时间线、采用区间、混音/字幕和待验母版；覆盖准确目标帧数，无未处理缺镜，声音/字幕完整。改锁画长度须复核声音/字幕。详见 [剪辑与交付](edit-deliver.md)。

## 11. 全片验收与交付（delivery）

**工作：** MCP 导出真实成片并完整解码，按镜头顺序审看全片；检查故事、人物/声音连续、黑帧/异常冻结/闪烁、音画同步、台词、爆音/噪声、字幕文字/时间和帧数/编码规格。未做视觉或听验明记未验证，ffprobe/ASR 不能替代。

**产出与完成条件：** 可播放成片 resource_id/链接，实际长度/画幅/声音证据，内容检查，可编辑时间线和整齐画布。回读确认输出节点和播放入口。正式剧本已覆盖，目标时长/规格通过，必要内容检查有证据，才宣称整片完成；安装技能、任务成功、技术导出都不能单独算完成。

## 媒介分支

漫剧与 AI 真人风格共用上述依赖，设计和摄影/表演语言随项目调整。实际真人拍摄在锁镜后另做人员/场地/器材、通告和现场镜头记录；可按地点拍摄，与故事顺序分开。AI 镜头保留 shot/take/版本和连续性记录，不虚设实体剧组。混合项目标记素材来源，统一镜头表与时间线。
