# 对白与声音绑定

## 按项目声音要求选路径

`NATIVE_AUDIO` 保留视频实测原生音轨；没有音轨就报告缺失，不能自行重配。若用户明确要求固定配音并去掉原声，按 `REBUILD_AUDIO` 的实际能力配置执行；同一句台词不能同时播放原声与重配声。

当前映射：`film_create_run.audioMode` 与 `plan.executionManifest.audioMode` 一致。重配模式在 manifest 的 `audioTrackBindings` 中记录 lineId、text、characterId、voiceVersionId、storyboardRowId、trackId、model 与实际音频 stepKey；视频选择关闭 generateAudio。音频步骤任务输入以 schema 为准，当前适配器要求 input.mode="audio" 与 input.config，并从 VoiceVersion 回填身份参数。不要把概念声线 ID 当作已创建的 VoiceVersion。

需要每个人物固定声音时，把 characterId 绑定到实际 VoiceProfile/VoiceVersion 或可复用的合法参考声音资源。记录参考 resourceId/哈希、渠道模型、确实支持的音色参数和一次确认样音。不同女主也有独立绑定，不能只按男/女共用一个声音；情绪可随镜头变，身份绑定保持稳定。

优先使用用户现有 `indextts2-v1` 渠道，但先核对当前协议能传哪些参考声音字段。模型目录若标记 voiceReference、voiceDesign 或 alignment 为 unknown，继续核实上游文档/适配器和实际样音，不能自动改为 supported。性别或年龄提示词不能替代参考音色绑定。

## 对白放在镜头中段（2026-10-03 用户确认）

对白和旁白优先在镜头中段开始并完整说完。开头先承接人物、空间、动作和环境声；结尾留词尾、呼吸、表情反应与下一镜的出口状态。不要默认在第 0 秒开口，也不要把整句拖到视频终点才说完。

- 先保存准确台词、说话人、说话方式、预计或实测长度，以及镜头内的对白开始和结束时间。声音方案、分镜时间节拍、实际提交提示词和后期采用区间必须一致。
- 可先把镜头前约 20% 留给承接，后约 20% 留给收束，中间安排对白；这是可调整的创作起点，不能机械套比例。15 秒例子：0–3 秒承接，3–11 秒说完对白，11–15 秒留反应；10 秒例子：0–2 秒承接，2–7.5 秒对白，7.5–10 秒收束。按台词长度、停顿和行动调整。
- 普通话可暂以每秒约 3–4 个汉字作为读本估时起点，停顿、语气和情绪另外加时间；这只是工作估算，不是模型能力或实际说话速度。已有配音以真实音频长度为准。预留句尾至少约 1 秒的可用余量，较长台词或恐怖停顿留更多。
- 台词放不进中段时，优先延长镜头、调整分镜或按句意拆成连续镜头；遵守用户总时长及渠道合法时长。不能擅自改台词、截词尾、把语音过度加速或把多句塞到最后一秒。
- 剧情或用户明确要求抢白、开场喊话、声音先行或结尾悬念时可有理由地偏离中段偏好；仍须完整保留应说完的句子，不把意外被截断当作叙事设计。
- H3 正文在该阶段真实智能 `@` 的动作描述旁写对白时间、说话人、原文和语气，例如：`3–10 秒，对应 @该阶段图；门外同一男子低声说 <d>[普通话] 林舟，我来接班了。</d>，主角保持沉默。10 秒后留反应，不再添加话语。` 智能引用必须绑定真实节点，示例文本不能冒充实际引用。
- 四张关键图及身份/衔接参考和提示词时间只是生成目标。生成后回查实际音频的台词开始、结束、句子完整性及说话人；ASR/对齐保留原时间基准，检查采用裁切是否会吃掉首字、尾字。人工或可用听审与口型检查分别记录。对白未说完或被剪辑截断的镜头不得作为对白通过结果。

## 时长、字幕与对白检查

- 台词与说话人绑定，保存准确文本及情绪/停顿。需要独立配音时先测音频实际长度，再安排镜头；不要为凑时长截掉词尾或将人物声音过度加速。
- 准确文本用于字幕内容；语音识别/对齐用于检查实际说出的内容和时间。中文采用多语言识别模型，不能照搬只识别英文的 `.en` 模型例子。
- 从视频提取音频做 ASR 辅助时保留时间基准，不能先删静音再直接复用原时间戳。多说话人还需核对台词归属，不能把整段识别文字当作正确说话人证据。
- 音轨存在、ASR 文本命中、人耳清晰度、声音身份、口型同步分别记录。未实际听验就不能声称吐字清晰；没有检查口型就不能声称同步通过。
- 口型工具仅在当前工具或模型能力确实支持时使用。普通替换音轨/混音不能修复嘴型。未接通时注明缺口，保留真实结果，不编造工具名。

使用软件实际支持的 VoiceVersion 和步骤输入格式；本文件不给上游编造字段。音色资源与业务资产持久保存，自动化恢复从已有绑定继续。
