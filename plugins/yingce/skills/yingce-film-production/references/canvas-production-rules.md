# MCP 画布制作规则

## 固定空间三步制作（2026-10-07 用户明确要求）

仅封闭室内的固定房间或相连室内空间，制作与接续先读 [房型、共用模型与机位流程](fixed-space-workflow.md)。顺序为：

1. 先采用或生成房型图，确定真实尺度、世界方位、门窗和相连空间。
2. 以该房型建立一个可保存、可重复取景的空间模型；家具固定，A/B/C 等机位在同一模型登记位置、朝向、镜头参数和视野，实际渲染并检查。
3. 模型与机位通过检查后，再按剧情制作四个关键状态、无边切图、逐镜绑定和视频；过渡实际进入时间线。

户外不强制房型图与建模，使用相关环境和人物参考。通用自动执行和已归纳纠错见 [剧本到成片](script-to-film-automation.md)，跨镜距离见 [距离台账](spatial-distance-continuity.md)。下方带本片地点、人物、模型或并发数的历史条目按项目需求适配，其他用户不继承本片的付费授权。

不同景别只改变摄影机/镜头和投影，不改变房间或固定物的物理间距；人物路线、朝向、视线和道具状态逐阶段说明。已有采用素材复用，规则升级不触发重生。实际模型源、机位图和原生导演场景分别记录，不能用标题或 metadata 冒充建模完成。

## 空间方位与四宫格过渡（2026-10-04 用户纠正）

- 过渡使用四宫格，取消本片两宫格方案。四格分别表达不同的连续动作关键状态，不能仅重复站姿。
- 先从已采用户型图确定固定世界方位与相对位置，再按每格摄影机位置换算画面左右。摄影机换向只改变画面投影，不改变家具、门窗、人物之间的真实位置与距离。禁止把朝北与朝南机位的左右描述混用。
- 本片卫生间北墙为洗手台与镜子，南墙为唯一出口D1，两墙正面对立；面向洗手台的林巡必须先转身180°再朝南出门。出口直接通入主房间，不能新增门洞、套门框、走廊或第二个房间。镜中门的反射不能生成另一扇实体门。
- 用户确认D1为灰白抹灰墙上的普通敞口，没有银色金属包边、木框或装饰门框；不要把银色镜框复制到出口。固定机位下门洞投影尺寸保持一致，人物走近只改变人物尺度。关键阶段须确实分别位于洞内、跨洞口、洞外通道，不能全部提前进入主房间。
- 每格明确人物站位、身体朝向、头与视线、前后脚、左右手及道具；明确摄影机朝向、移动路线、可见与画外物体。物理上在摄影机身后的门正常可以不出镜，不能为了展示门而把门搬到洗手台旁。
- 同一主房间朝北：画面左床、右桌右窗；朝南：画面右床、左桌左窗。表格或镜头描述只有在对应机位成立时才沿用。桌上既有玻璃杯、纸、面包、收音机与床头钟等保留材质和实际状态；正常遮挡不等于消失。
- 参考按用途选择：前镜采用末阶段锁动作，平面图锁几何，当前场景图锁材质与布局，人物三视图锁身份。通常先选4–5张清晰且必要的参考，按本镜实际需求调整；每资源只引用一次，不用失败母图引导再生成，不混入相反机位而不给出明确用途。
- 提示词直接写入目标图片的原生输入框，以中文分类标题组织；实际智能引用采用稳定节点绑定，并放在相关段落内。不能另建提示词文本卡或只写没有绑定图片的标签。
- 空间验收逐格检查对立墙关系、门框数量、出门前转身、脚步路线、机位轴线、物体尺度与距离、桌面状态、脸与肢体。任务成功只证明取得图片；不通过时记录具体格子、错误关系和正确关系，加入下一次提示词并重生成，不能切图或进入下一镜。

## 同镜累计缺陷与审核门禁（2026-10-04 用户明确要求）
- 同一镜头每次出现的新缺陷，累计写入该镜头的失败台账，记录版本、真实资源、阶段、位置、实际错误、目标状态和下一版验证项；不能修复新问题后忘记旧问题。
- 下一次实际提交的提示词必须有“本轮重点纠正”：逐条描述已观察问题发生在哪格/哪个部位、正确形态及动作连续性，以及禁止重复的错误。此前已通过内容继续锁定。并先消除提示词中的冲突，例如左手不能同时要求撑盆与腹侧。
- 找原因：区分参考图本身不合格、动作指令冲突、空间/视角约束不足、道具身份混淆、反射或遮挡歧义、成图细节不足，以及渠道/软件请求错误。根因尚不确定时记录假设，不把猜测当结论；据实际结果改提示词或输入。
- 用户否决的镜头立即撤回采用状态，清除画布失败母图与切图并保留任务/资源证据。只从合格角色、场景、道具和前段合格状态新生成，不引用被否决的本镜宫格。
- 新版先逐格看母图，再切图并逐张看原始像素；逐条复查累计旧缺陷是否重现，也检查新的缺陷。存在 failed 或关键项 not_checked 时禁止提交后续镜头；全部通过才恢复采用并继续。不得用任务成功替代视觉审核。

真人生图/四阶段母图写提示词前读取 [图片提示词与逐项审核](image-prompting-quality.md)，结合官方 imagegen 提示词方法及本用户已确认规则；实际生成沿用指定衍图渠道。

用户于 2026-10-02 至 2026-10-03 确定的制作顺序与引用要求。启动 MCP Agent 后，制作或继续漫剧、真人短片及其资产时先读取本文件；接续时按已有真实产物完成剩余阶段。

1. **确认当前画布。** 通过真正的 MCP 调用确认本插件所属便携版和目标 canvasId，读取最新上下文与分镜。写操作携带 expectedCanvasId、revision、stateHash，并回读核对。
2. **生图直接引用图片。** 需要已有角色图、场景图或道具图时，从所需图片直接连到目标图片，图片引用链留在图像区域。提示词的智能 `@` 引用绑定真实节点，生成前核对实际输入。
3. **先完成全部图片，再关联资产，再生成视频。** 在剧本与分镜需求明确后，生成或复用本片所需人物、场景、道具以及计划中的镜头首帧、尾帧/关键图。检查身份、服装、画风、场景空间、构图、尺寸与连续性；所有所需图片通过检查后，再把采用图片逐镜绑定到真实分镜行。可以提前登记资产需求，实际关联使用已完成并验收的图片。视频从这些已完成的分镜行生成。返工先修复受影响图片及引用，再继续受影响视频。
4. **每镜头按需关联。** 逐行分析本镜头实际出现和需要保持一致的角色、环境、服装与道具，只关联需要的资产。换场景或人物版本时更新该行的绑定。每行独立设置 assetBindings、characters、requiredAssetRoles；移除本行无关的资产及全局引用，避免默认给全部镜头复制全套图片。
5. **分镜行是视频的输入来源。** 对应分镜行直接连到对应视频，读取该行提示词、台词、采用资产及已就绪首帧。视频继承该行的真实素材，不再自动补重复的资产到视频连线。需要首尾帧控制时分别明确指定，并以当前模型实际支持的能力提交；普通参考图不能冒充尾帧约束。
6. **引用、提示词和连线一致。** 关联资产的可见线、分镜行绑定及智能 `@` 引用须对应同一批稳定节点 ID。回读每个镜头的实际输入，确认无丢失、重复或混入其他镜头素材。复用已有媒体与真实任务，避免重复生成。
7. **按制作顺序整理画布。** 从左到右划分图像区、分镜区、视频区，分别只放图像、分镜和视频；剧本、规则与检查记录另放文档区。各区按数量、尺寸排列成均衡网格，对齐留白，媒体卡片逐个可见。保留必要关联线并清理重复绕线，每批结束及交付前回读核对节点与素材。
8. **按现有授权与规格执行。** 沿用指定模型、目标时长、画幅和费用授权；生图默认单次一张，确有多个独立资产需求时逐项生成。仅整理规则时保存说明；实际生成、检查和交付分别以真实工具结果为依据。

## 2026-10-02 补充：分镜字段、首帧连线与配乐

- 按镜头需要选择并填写画面描述、镜头意图、景别、运镜、表演调度、时间节拍、连续性出口与音效，不强制全部启用。勾选只是显示列；采用的约束必须进入实际提交的提示词并核对输入。
- 关联资产栏中的每张采用图，包括本镜首帧，都要有图片到对应分镜行的可见线；首帧作为先前生图产物，也作为后续视频输入。视频只连对应分镜行，避免重复图片到视频线。同图多个角色保留角色信息、仅一个缩略图和一条该行输入线。
- 配乐按场景、叙事情绪与节奏决定，不默认整片无配乐，也不强制每镜都有。10–15秒长镜头可适当配乐，但时长本身不是唯一依据。先在声音方案中规划音乐进入、延续和退出的位置；缓入缓出时长按音乐乐句、动作和剪辑节奏确定。同一场景或情绪连续时，音乐可跨镜头保持连贯，不在每个切点重新起停；下一镜不需音乐时提前自然淡出，保留环境音作声音桥，避免硬切的分割感。换场景确需换乐时采用合适的乐句收尾、交叉淡化或有叙事理由的停顿，压低配乐以保持对白清晰。统一规划音轨，防止模型逐镜意外配乐互相冲突；提示词并非验收，须听审实际输出及切点。仅有音轨和完整解码不能证明配乐合适。当前测试片按用户要求保留，不返工。

## 镜头衔接与真实输出规格

- 当前默认每镜使用自己的切图1为首帧，前镜末格只用于连续状态参考；下一镜第一关键时刻应有新动作推进。只有用户明确要求无缝延长原视频时，才按真实模式使用其实际末帧作为延长首帧，这不是当前四宫格切镜的默认规则。景别或机位变化须匹配空间、动作与视线。
- 指定单条视频首尾帧须由当前渠道的模型操作、输入槽及实际调用证据支持。检查时读取最新能力；不能由模型名称、后缀或官方其他接口推定本渠道支持。当前 z0902 合同未声明尾帧，不把该限制推广到其他模型。
- 视频面板同步本任务提交参数；成功结果根据真实原视频尺寸显示已知分辨率档位，精确像素和实测时长另外保留。未知规格明确记未确认，不借用全局默认值。技术解码、内容审看和声音听审分别记录；未听到声音就不标注对白清晰或配乐合格。

## 图片验收与关联更新

所有图片完成并通过检查后，先确认画布当前显示的是验收采用的新版本，再逐镜更新关联资产；重新生成图片时不得沿用旧资源绑定。关联后通过 MCP 回读节点、资源 ID、缩略图来源和可见连线，确认它们都指向同一采用版本，才进入视频生成。

生成任务成功、生成时间最新，不等于图片已验收采用。用户指出采用图片错误时，撤回受影响镜头的就绪状态；核对用户所指的正确版本，更新真实图片资源和逐镜引用后再继续。显示修复与采用版本替换分别回读验证，不把刷新预览当作已经换图。

已采用或修复合格的图片由真实资源 ID 锁定；历史任务回挂、旧提交重放和延迟素材入库不得自动改变采用版本。只有明确开始新一轮生成或选择替换素材才可更换图片。发现版本不一致时保留现有历史结果，先核对正确版本并复用恢复，再验证画布图片、分镜缩略图、放大预览及实际视频输入全部一致。

## 逐镜关联示例

- 同一参考图片只引用一次：人物、场景、道具按真实节点和资源去重。直接生图引用与分镜自动补入的引用不能复制成两组；多个角色标签仍共用一张缩略图、一个实际媒体输入和一条目标输入线。更新分镜后再次回读数量，不因关联资产重新生成图片。

| 镜头实际需要 | 应关联的图片 |
| --- | --- |
| 镜头 1：人物 A 在场景 A 行动 | 人物 A + 场景 A |
| 镜头 2：仅需人物 A 外观参考 | 人物 A |
| 镜头 3：人物 B 到场景 B，手持道具 C | 人物 B + 场景 B + 道具 C |

此表说明选择方法，具体资产以本片逐镜需求为准。
## 四关键帧方案与提示词准确性（用户采用规则）

- 用户于 2026-10-02 看过四关键帧及六关键帧对比后，选择四宫格作为后续默认方法，并更正顺序：先分别完成人物、场景、道具参考资产并验收；这些资产不要求做成四宫格。再按每个镜头实际需要，直接连接相关资产，生成该镜头四个连续动作状态的四宫格。切成四张独立图片并检查全部通过后，再逐镜关联采用图片，最后从分镜行生成视频。六宫格保留为可选对比方案，不自动替代四宫格。
- 生图提示词按左上、右上、左下、右下逐格写清动作状态、人物视线、左右手、道具位置和高度。固定人物身份、服装、场景空间、光线、机位与道具数量。相邻格要有可读动作差异，不能用几张几乎相同的画面冒充四个步骤；固定物件若漂移或手部出错先修图。
- 宫格切图后检查数量、顺序、构图、实际像素及切边；同一分镜的动作参考以四张采用切图为主，不再把母图、旧失败图或相同切图重复送入。确需补充的身份/场景参考按本镜实际需要及模型参考上限另行选择，不默认复制全套资产，不能超限。
- 视频提示词明确 Picture 1/2/3/4 各自的真实节点、动作和时间段，并描述相邻状态之间的物理动作；核对实际输入顺序与提示词一致。一个连续镜头不生成四格拼屏、幻灯片或无理由切镜。
- 多图参考只是视觉动作指导，不等于接口提供四个严格时间关键帧或首尾帧约束。不能保证四张图都会在指定秒数精确重现；实测检查动作顺序、过渡、人物/道具连续性后再评价方案。裁出的每张图像素少于母图，准确记录，不以插值放大冒充新增细节。
- 若另行进行六宫格对比，采用三列两行，按左上、上中、右上、左下、下中、右下排序；逐格检查手部、动作、道具与分格边界，严重变形的格不得进入分镜或视频。当前 z0902 最多六张参考图，六张动作切图已占满上限，不能再追加重复母图或额外身份图。先检查全部切图再关联，准确记录实际母图/切图/视频规格；采用与否以实际效果和用户反馈为准，不把参考数增加等同于效果必然更好。

## 单镜头四图与时间节拍（2026-10-02 确认）

1. **先确定单镜头长度与四个关键状态。** 按该镜头要表达的事件、动作、表演和台词决定长度；用户指定时长时沿用指定值。四张图覆盖该条视频的起始状态、动作展开、关键变化和结束状态，以实际剧情选择最重要的四个节点，不把每个动作都另拆成视频，不固定每镜 3 秒，也不机械平均分成四段。
2. **先写时间表，再生成四宫格。** 将总长 T 分成四个连续阶段：0–t1、t1–t2、t2–t3、t3–T，覆盖整条视频且不留空档；明确每段的事件、主动作和代表姿态。图 1 描述开场状态，图 2、图 3 描述中间关键状态，图 4 描述结束状态；记录各图的目标出现时刻及前后动作。阶段范围表示动作的展开区间，不表示静止展示图片。

下表只是 15 秒示例，分界和中间关键时刻应随具体剧情调整：

| 关键图 | 动作阶段 | 代表画面的目标时刻 | 叙事作用 |
| --- | --- | --- | --- |
| 图 1 | 0–3 秒 | 开场 0 秒 | 建立人物、场景及起始状态 |
| 图 2 | 3–7 秒 | 约 5 秒 | 第一项关键动作已经展开 |
| 图 3 | 7–11 秒 | 约 9 秒 | 关键变化、反应或动作结果 |
