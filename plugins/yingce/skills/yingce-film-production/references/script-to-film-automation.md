# 从一个剧本接管制作：MCP 工作流与已归纳经验

更新：2026-10-07。用于后续用户提供剧本后，由 Agent 接管计划、素材、生成、检查、返工、剪辑及交付。它归纳本片反复纠正的问题，具体执行仍按 [正式制作流程](formal-production-workflow.md) 和当前 MCP 能力。

只要求学习、归纳或整理规则时，使用已保存的记录总结，不启动旧画布审查或生成。用户确认已完成的项目保持原结果；以下执行主线在新制作或获授权接续时使用。

## 启动输入与适用范围

以剧本为主要输入，先读取真实连接、项目、采用资产、模型默认项和当前用户要求。已有渠道与可用模型配置时，Agent 自主完成普通创作选择；剧本未指定时长时按对白、动作与故事节拍安排并记录假定值，不自动套本片 180 秒或固定镜头数。

沿用当前用户已授权的范围和偏好；其他使用者不能继承本对话的付费或数据操作授权。确实缺少必要接口、模型配置或费用权限时只问必要项，不额外加入逐阶段确认。

先逐场分类：

- **封闭室内**：按 [房型图 → 共用空间模型与机位 → 关键帧和视频](fixed-space-workflow.md)；有合格产物就复用。
- **户外开放场景**：使用环境与人物参考，正常拆镜和生成，不强制房型图/三维建模准备。
- **剧情跳时/跳地点**：按剧本剪切；连续走出房间或经过相连门洞则交代路径与过渡。

## 执行主线与持久记录

制作或接续先按 [自检闭环](self-check-workflow.md) 读取实际资源和当前验收证据，处理待检查队列；每张切图、每个实际视频及整片分别记录。原生 `film_self_check` / `canvas_read_quality_reports` 是只读入口，内容评价、修复和复查仍由具备相应视觉/声音能力的 Agent 完成。

1. **读取与拆解**：确认 canvasId/projectId/runId，记录剧本版本，提取故事节拍、人物、场景、道具、准确对白、时长需求。禁止凭历史镜号跳过中间剧情。
2. **规划空间和镜头**：封闭室内采用房型和共用模型，登记机位。逐镜确定意图、景别、对焦对象、动作、视线、路线、时间节拍及首末状态。必要时建立 [距离与状态台账](spatial-distance-continuity.md)。
3. **复用基础资产**：先找已有角色、场景和道具版本。已合格资产不额外重复添加；确有缺项才制作。真人身份与服装引用同一采用版本。
4. **关键图**：每镜提炼四个不同的关键事件/动作状态，覆盖该视频完整时间安排；前镜末态用于连续性，本镜首格推进行动。检查母图全部四格，再无边切图并审看每张。
5. **绑定与提交**：全部所需图片完成后，按每镜实际需求绑定真实独立切图。首帧为本镜切图1，切图4的用途以渠道能力为准；四宫格母图不充当首尾帧。视频从对应分镜行生成。
6. **模型与提示词**：查模型合同，按用户指定模型调用其指南。确认 H3 才读官方技能和中文适配；每张原生智能 @ 引用嵌入起作用的段落，引用、编号、缩略图、连线和请求一致。
7. **候选与检查**：按输入依赖及最新授权分批生成。媒体请求并发不等于画布写入可以共用旧 revision；每次写入刷新版本。候选可并发，正式采用按故事/依赖顺序，任务成功不能代替内容通过。
8. **返工与恢复**：先查原任务，再区分终态失败、查询超时、视觉失败和显示故障。视觉失败记录具体问题及正确状态，累积未解决缺陷进入下一版；输入已正确的明确终态失败按现有授权重试。保留真实 retryOf 和幂等身份。
9. **剪辑与声音**：按剧情采用合格区间，转场实际进入时间线。对白按原句和说话者完整保留；按用户要求处理不合适声音，不擅自把原生声音全部换成配音。未听审不标音质/口型通过。
10. **交付与整理**：真实导出、完整解码和内容检查后交付播放文件与可编辑项目。每批整理受影响区域，图像/分镜/视频按顺序，切图和视频独立可见；只有用户要求整体重排才使用整画布布局。

最少保留：剧本/分镜版本、空间与机位依据、采用资源和真实输入、模型/技能版本、run/step/attempt/taskId、检查证据、失败与修正、最终采用区间及交付文件。现有历史计划只供追溯，不盲目重放收费。

## 从本片问题提炼的通用规则

| 已观察问题 | 以后生成前的检查 | 返回后的处理 |
| --- | --- | --- |
| 房间布局、门洞大小或边框改变 | 封闭空间使用同一模型，机位有对应视图；门、门洞、镜框分别记录 | 对照真实视图，修受影响阶段，错误图不再引导后续 |
| 换镜后人物与桌子间距变大 | 同一测量锚点、单位、坐标与动作记录；相机变化不改物体位置 | 查计划坐标与透视，明确几何漂移还是镜头观感变化；无标定不假报米数 |
| 去卫生间后桌面物件没了/变材质 | 道具按身份、承托物、材质、数量及状态登记 | 全景应可见却消失则失败，正常近景出画单独记录 |
| 后镜首格复制前镜末格 | 写“继承状态”和“本镜新增动作” | 比对相邻关键图和实际视频末态，重复构图未推进则修 |
| 四格后几格没有动作区别 | 逐格说明新增剧情信息，不按等时长凑四姿势 | 四格逐张审看，近似重复不能通过 |
| 人物方向错误、穿墙或跳房间 | 身体、头、视线、走向分别描述，路线经过既定门洞 | 审看首中尾、转身、跨门和落点，必要过渡实际采用 |
| 首尾帧用了母图、关联漏图或重复 | 真独立切图按用途绑定，按资源去重、核验上限及实际顺序 | 回读真实面板/请求，修引用后才提交；不重生合格图 |
| @文字没有缩略图、提示词另拉卡 | 提示词在原生输入框，@绑定稳定节点并内联 | 查智能绑定，不把手打标签当图片已发送 |
| 镜中脸、手腿、工具或人数错误 | 同一人时序关系、左右手和工具数量明确，反射按剧情 | 放大逐格与逐时刻检查；正常裁切与畸形、模糊分开 |
| 超时重复扣费、旧任务覆盖新图 | 查询原 taskId，采用版本独立记录，稳定幂等键 | 未明不重发；只有真实结果回挂，历史结果不覆盖采用版 |
| 失败图、占位、切图叠放 | 规划容器、标题和独立网格，保留引用路径 | 按授权清理失败/无用节点，任务证据保留，回读采用资源 |
| 视频顺序错、过渡未使用、语音被截断 | 锁定主镜/过渡的时间段和准确对白窗口 | 时间线核对实际覆盖、桥接及词头词尾，未检查项如实记录 |

表中的可能原因要由实际输入和产物核查，不把模型机制猜测写成已证实根因。单片的林巡、钢门、卫生间、异常镜像及渠道上限不是所有剧本的固定模板。

## 启用新版规则的方法

当前插件文件与软件技能库是两个入口：文件更新不会自动替换软件已安装的 ZIP 技能版本。需要同时维护便携插件、当前 Agent 技能、软件有效技能包和迁移副本。

在本机作者所有的技能更新时，使用真实包更新接口保留 skillId，新增 versionId；回查 skill_catalog/skill_search，并用 skill_read 读取新增参考。当前已有制作运行沿用锁定版本，规则升级不静默改写任务指纹、采用媒体或触发重生。

调用工具前读取实际 schema。未接入的深度/三维/控制视频能力如实记录；安装提示词技能不自动增加模型能力。配置和调用范围就绪时，可以从剧本自动执行上述步骤，但每项完成仍以真实产物和内容检查为依据。
