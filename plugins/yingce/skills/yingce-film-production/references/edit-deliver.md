# 剪辑与交付

## 精确长度

以目标时间和交付帧率建立时间线，最后的画面终点必须等于目标帧数。若时长不落在帧网格上，明确量化策略，不能声称物理上不可表示的精度。

示例：180 秒、25 fps 对应 4500 帧。片头、片尾、字幕和转场占用总时长；片段跨轨重叠按时间线覆盖计算，不能直接相加。素材实际可能比请求略长，按采用区间裁切。需要补镜头时补有叙事作用的镜头，不能重复循环素材假装完成剧本。

帧率采用用户要求或经验证的交付设置。按半开区间 [startFrame,endFrame) 规划：4500 帧的编号为 0—4499，结束边界为 4500；实际工具需要毫秒或包含末帧的参数时按 schema 转换。

优先用衍图时间线与 `film_render_timeline`。高级字幕动画/片头再用 Remotion：读实际 `remotion-best-practices` 入口并按其相关参考实施，不假设只安装技能就已有 Node 包或浏览器渲染依赖。预览选择未占用端口；不抢衍图服务的端口。

## 格式与声音

使用 FFmpeg 时读 `ffmpeg-ops` 的当前相关参考，先 probe 原素材、确认编码器/滤镜。Windows 采用 PowerShell 参数数组或 Python subprocess 参数列表；不要直接执行 Bash 示例中的重定向、管道、续行和变量替换。

精确裁切需解码/重新编码，不能依赖关键帧 stream-copy 的表面时长。统一帧率、分辨率、音频采样率和时间基准后再合成。参考图或模型输出的对齐误差允许按项目合同处理；方向颠倒不能当作小误差。统一画幅用保持比例的裁切/留边，不拉伸人物。

对白与音乐/环境声分层，按场景安排声音桥接和音乐避让。需要响度规范时使用真实测量与适当的两遍处理，不把降噪或变速当作通用修复。变速若用于校正长度，atempo 倍率为原音频长度/目标长度。

## 完成证据

核对全片帧数/音视频长度、画幅、分辨率、全解码、采用镜头顺序、黑帧/突变、字幕文本/时间、人物和声音连续性。`film_verify_delivery` 的格式检查与实际画面/听验分开报告；缺少语义检查时保留 uncertain。

交付真实成片 resourceId/播放链接、画布可见入口、可编辑时间线和简洁质量记录。技能安装、生成任务成功、转写命中或导出成功都不能单独代替整片质量验收。
