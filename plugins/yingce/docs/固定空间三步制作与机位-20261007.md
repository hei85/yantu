# 固定空间制作：房型图 → 共用模型与机位 → 关键帧和视频

更新：2026-10-07。本三步流程只用于封闭室内、同一房间或相连的封闭室内空间。户外开放场景使用对应环境与人物参考，不强制房型图或三维建模准备。封闭场景先规划房型，再以房型建模，最后生成视频。已有房型、模型和采用素材先复用；接续或只修改引用时，不重新制作已通过的图片。

需要保持人物与桌椅的跨镜距离时，再读 [空间距离与连续性](../skills/yingce-film-production/references/spatial-distance-continuity.md)：使用同一锚点和世界单位，分别登记固定物、人物走位与摄影机变化。

## 第一步：确定场景房型图

1. 先查画布和项目已有房型图、结构参考及最新用户纠正。已有明确房型图就采用它；没有时才按剧本和授权生成或绘制一张，并检查结构。图片生成返回成功不代表尺寸、门窗和连通关系正确。
2. 登记空间版本、真实图像节点/资源、单位、比例、原点、世界东南西北及高度轴。记录房间尺寸、墙高、墙厚、门窗所在墙及开口宽高；多房间还要记录它们共用哪个门洞及通往哪里。无尺寸部分标为待确定或有依据的假定值，不能声称由图片精确测得。
3. 登记固定床、桌、椅、柜、盆、镜等的尺寸、世界位置和朝向；记录可通行路线、桌面道具锚点和光源方向。门洞、门板、镜框分别建项，不能互相替代。
4. 用文字说明相对关系供检查，例如“洗手台在卫生间北墙，出口在对面的南墙”。所有后续机位都使用这组世界关系；画面左/右随相机朝向转换，不能代替世界方位。

**产出与进入条件：** 已采用房型图和空间规格；连通关系、关键尺寸和家具位置有记录，能解释剧情走位。最近用户纠正优先于旧图标题与历史提示词。由 Agent 在既有授权下检查，不要求用户逐步审批。

## 第二步：从房型建立一个共用空间模型，固定机位

1. 将同一空间规格落实到可保存、可重新取景的几何模型。可采用衍图真实导演场景，或已有的确定性参数化模型源。记录原生 sceneId/sceneHash；使用外部模型时记录源文件、文件哈希、单位与坐标轴。几张独立生成的房间图本身不足以证明已建立共用模型。
2. 以真实尺寸建立墙体、门洞、窗洞与家具，给物体稳定 ID；检查高度、尺度、相对间距和遮挡。同一住宅的相连房间用同一世界坐标连接。新建对象的默认位置不是最终位置，按规格设置变换并回读。
3. 结构、固定家具、材质和光源作为空间基准锁定。道具可使用简化代理体，但有独立身份、尺寸、材质、承托物和位置；细节外观继续引用已采用道具图。尚未建入的小物件明确登记，不能报告“全道具已建模”。
4. 在同一模型登记 A、B、C 等真实机位，每个机位有自己的位置、朝向、镜头参数和版本。从同一模型渲染各机位的结构图；增加反打或特写时，先在原模型新增或明确修订机位，再取景。不得为每个机位重建房间或搬家具来适配构图。
5. 审看多个机位：对面的墙是否正确、门洞是否同一个、单门是否变双门、椅子是否存在、床桌是否同尺寸、路径是否可走。结构视图足以确定布局即可，不把低模结构图冒充正式实拍素材。

### 机位表必填内容

| 项目 | 记录内容 |
| --- | --- |
| 归属 | 空间版本、模型版本/哈希、cameraId、机位版本 |
| 位置 | 世界坐标、离地高度、与主体/固定物的距离 |
| 朝向 | 注视目标、水平和俯仰方向；明确坐标轴及旋转单位 |
| 镜头 | 实际焦距与传感器依据，或实际 FOV/投影参数；画幅比例 |
| 镜头用途 | 全景/中景/近景/特写、前中后景、对焦对象、可见物与遮挡 |
| 行动关系 | 人物站位、身体朝向、视线、路线、动作轴线 |
| 运镜 | 固定，或起点、终点、路径和时间；核对墙、窗、家具与通行空间 |
| 产物 | 此机位真实渲染图的节点/资源和检查结果 |

“固定机位”指机位参数有记录、重复调用可复现。同一影片可以使用多个已规划机位；每次改相机须说明原因和新参数。只写“平视中景”不足以确定房间中的摄影机位置。

拉远、变焦和裁切分别记录：拉远改变摄影机位置，变焦改变镜头视野，裁切改变画面范围；三者都不改变家具的世界位置。物理间距固定不等于屏幕像素间距固定。新角度没有可用空间时调整镜头方案，不能穿墙、穿窗或扩大房间。

**产出与进入条件：** 一个可读取的模型源、机位表、从该模型导出的结构视图及检查记录。模型与房型相符，各计划机位能解释视野、距离和遮挡后，才进入第三步。模型图与采用实拍外观不一致时记录具体差异，不静默覆盖用户已确认布局。

## 第三步：按已规划机位生成关键帧，再生成视频

1. 选用本镜对应的模型取景图锁结构，采用场景图锁材质和外观，身份/道具图锁人物与物件。每张参考明确用途，使用最少且足够的相关图片；不混入相反机位图而要求整体复制。实际数量受当前渠道能力限制，当前六图方案只适用于已核实的项目。
2. 四宫格提炼本段四个关键事件或动作状态。每格关联空间版本、机位、时间、人物站位/朝向/视线、双手和道具状态。若是一条连续运镜，四格使用同一路径上的已规划位置；若有切镜，先明确镜头安排，不能让模型自行跳机位。
3. 场景固定，人物按剧情行动。前镜末格只迁移人物、空间、道具及动作状态，后镜首格必须推进行动；不能复制前镜末图或用搬动桌椅制造画面区别。同一人物多时刻参考不会产生多个实体人物。
4. 先逐格审看母图，再切成四张无边图、逐张审看并分开排列。全部本片所需图片有可读、已检查的资源后，绑定对应分镜行。视频首帧用本镜独立切图1，切图4的严格尾帧用途须由渠道实际支持；四宫格母图不充当首尾帧。
5. 视频正文按时间写动作、运镜、原句对白和声音，原生智能图片引用放在对应段落，实际请求与分镜行、缩略图和编号一致。确认启用 MiniMax H3 时加载官方 h3-prompt-writing，再用本地中文适配；其他模型不套 H3 专属语法。
6. 相连房间的连续位移交代转身、走到原门洞、跨门及到达后的新状态，规划过渡关键图。检查通过的过渡可成为独立视频段或相邻视频内的明确采用范围，必须实际进入成片时间线。剧本明确跳时/跳地点时按剧情省略路途。
7. 真正返回后审看多个时刻和首尾，复核机位、方向、尺度、距离、遮挡、道具及动作顺序。AI 参考与文字坐标不能保证精确几何；出现漂移仍须修复，不以提示词写得完整代替验收。

**产出与进入条件：** 合格的独立关键图、真实逐镜绑定、真实视频及采用区间。检查未通过的部分先修复，不把任务成功标作空间通过；已合格素材和已有授权继续复用。

## 空间与物件检查

- **房型：** 同一个门洞、相同的宽高与边缘材质，开口通向原来相连空间；不新增第二层门框、窗、房间或走廊。
- **距离：** 固定家具的世界位置与间距不变；人物到家具的距离只有真实走位或搬动物件时才更新。同一锚点原为 5 米，纯换机位后仍为 5 米；若要变成 10 米，先有可解释的行动与路径。相机变化影响透视，不以相同像素距离要求不同视角。生成前核对真实坐标，返回后另查实际内容；单幅未标定图不能证明精确米数。
- **方位：** 身体朝向、头部朝向、视线目标和行走方向分别记录。朝北与朝南机位的画面左右不能混用；镜中方位另核对。
- **物件：** 收音机仍由木桌承托，杯子仍是同一材质与形状，椅子在原位置。近景裁掉物体可记录正常出画；全景中本应可见却消失必须修复。
- **剧情状态：** 拿走、放下、吃掉、打碎等只更新对应状态；每次变化有角色、时间和位置依据，不能离开房间回来后整桌自动清空。
- **人体与反射：** 空间正确不免除脸、手、腿、镜中身份和反射动作检查。镜子按既定剧情规律处理，不为修空间临时改变规则。

## MCP 操作与能力边界

先以 runtime_diagnostics、canvas_list_open_canvases、canvas_get_context 确定连接及画布，再读 canvas_get_capabilities 的实际工具与参数。第一次完整读取，后续用简要上下文和目标详情，保留稳定 ID。

1. 用 canvas_list_director_scenes、canvas_get_director_scene 查可复用模型。没有原生场景时如实登记；已有参数化模型也可以作为空间源，不假称它已导入导演工作台。
2. 确需新建原生场景时，按当前 canvas_create_director_shot 的真实模板和接口建立；原模板本身不算目标房型。用 canvas_add_director_object 和 canvas_update_director_object 落实受支持的几何体、演员及变换，再回读核对。使用自定义几何模型时走真正可用的建模/导入途径。
3. 在同一场景用 canvas_add_director_camera、canvas_update_director_camera 建立机位，镜头通过真实 cameraId 关联。参数化模型则保存同等的相机参数与对应渲染图。
4. 通过匹配的导演工作台及 canvas_capture_director_frame 取得实际 CAM 图；记录 sceneId、shotId、cameraId、sceneHash 和真实 PNG 资源。只改标题、metadata 或提示词不能代替建模或真实取景。
5. 直接录制三维模型时使用实际 CAM 视频工具；AI 视频则使用已检查关键图与当前模型渠道。两者的产物与几何约束能力分别记录。

所有写入使用该工具要求的最新版本前置条件；普通画布写入核对 expectedCanvasId/revision/stateHash，导演专用写入核对 expectedSceneHash，采集按其 schema 同时携带两组。连续修改须回读新版本，不能并发写同一旧哈希。生成任务未明先查原任务；已采用图片不因规则升级重生。

当前 canvas_update_director_scene 只开放场景名称、背景、环境强度和网格开关，不能把整套模型塞进 scene patch。新增对象当前支持 primitive/actor，不能假设工具支持任意 mesh/GLB 导入。房型图到几何模型是建模工作；没有证据时，不宣传自动一键识图建模能力。确有接口缺口先记录具体缺口，再采用已授权、真实可用的建模路径。

## 本片可复用依据：ROOM_V3

现有房型图和三张低模机位图已在画布。实际参数化源 room-blockout-v3.py 使用一组共用家具坐标、透视投影和深度遮挡，只在渲染 A/B/C 时改变相机。它是确定性空间模型源；PNG 是它的取景产物。

源模型单位为米，X 向东、Y 向北、Z 向上，主房间 5×6 米，附属卫生间 2×2 米。移入其他三维引擎时先转换轴、单位、旋转和相机约定，不能原样套坐标三元组。

| 机位 | 摄影机位置（东、北、高） | 注视目标（东、北、高） | 用途 |
| --- | --- | --- | --- |
| A | (2.5, 0.8, 1.6) | (2.5, 5.5, 1.2) | 主房间向北：左床、右桌窗 |
| B | (2.5, 5.7, 1.6) | (2.5, 0.3, 1.2) | 主房间向南：右床、左桌窗及南墙钢门 |
| C | (1.0, 6.25, 1.55) | (1.0, 7.9, 1.2) | 从卫生间入口向北看盆与镜 |

这些是本模型示例，其他房型不能照搬。当前投影画布为 1600×900、焦距参数 850 像素，不能没有传感器依据就称为 35mm。C 机位向北，出卫生间需要朝南行动并规划相应取景；不能把盆旁侧墙当出口。

源中 D1 为北侧连接主房间与卫生间的 0.9 米普通开口，无银色边框；D2 为主房间南墙钢门。部分旧图文字、旧提示词可能不符最新纠正，以最新采用空间关系为准。源未建全桌面小道具，也尚无原生导演场景登记证据；分别记录覆盖范围，不能说全部建模和导入完成。

## 失败后的修正与保存

逐项记录失败镜号/阶段/时间、真实资源、错误关系、应有关系、根因证据及具体修法。区分房型/模型错误、错误机位、引用错配、人物动作错误和生成漂移。

- 模型错误：修相应结构或变换，升级模型版本，重新导出受影响机位并复核依赖。
- 模型正确而取景错误：修 cameraId、镜头参数或路径，不改房间尺寸。
- 模型和取景正确而生成漂移：用对应结构图与外观图，优化本轮具体纠正；不加入互相冲突的参考。
- 文件技能和软件技能库分别维护。更新软件作者所有的技能时用原生包更新接口保留 skillId、新增版本，回查有效目录并读取新参考；不只改本地文件就声称 MCP 已启用。已有运行保留锁定版本。规则写入不等于模型已创建、旧媒体已修复或审核已通过。

最少保存：空间版本及房型资源 → 模型源/哈希或 sceneId/sceneHash → 机位参数和渲染资源 → 镜头/阶段/动作状态 → 实际图片绑定与视频任务 → 采用范围及检查记录。每层都有真实出处，接续时可查回。
